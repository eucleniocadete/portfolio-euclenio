# Guiões Detalhados para Instagram Reels (@_euclenio_)

Este documento apresenta dois guiões completos e prontos a gravar para os Reels de desenvolvimento de software. Cada guião inclui orientações de câmara, texto dinâmico no ecrã, locução exacta e sugestão de legenda para publicação.

## Vídeo 1: As 3 Extensões de VS Code que Salvam Horas de Desenvolvimento

*   **Duração estimada:** 45 a 50 segundos.
*   **Estilo:** Dinâmico, ecrã dividido entre o autor a falar diretamente para a câmara e gravações rápidas de ecrã (screencast) do VS Code.
*   **Áudio de fundo:** Batida tech/lo-fi em ritmo moderado.

### Estrutura Cena a Cena

**Cena 1: O Gancho (0:00 - 0:05)**
*   **Visual:** Plano médio do autor no escritório, com iluminação limpa e monitores ao fundo com código visível. Texto grande e colorido no centro do ecrã: *"Ainda usas o VS Code sem isto?"*
*   **Locução:** "Se usas o VS Code para programar e ainda não tens estas três extensões instaladas, estás a perder horas de produtividade todos os dias."

**Cena 2: Extensão 1 - Produtividade/IA (0:05 - 0:18)**
*   **Visual:** Transição rápida para gravação de ecrã (screencast) a mostrar a instalação ou o funcionamento de uma extensão de inteligência artificial ou auto-complete no VS Code. O nome da extensão surge em destaque no canto superior.
*   **Locução:** "A primeira é [Nome da Extensão de IA ou Preenchimento Automático]. Ela antecipa cada bloco de código que escreves, poupando-te de repetir funções básicas em backend."

**Cena 3: Extensão 2 - Formatação e Estética (0:18 - 0:30)**
*   **Visual:** Ecrã dividido: em cima o código desorganizado, em baixo a formatação instantânea a aplicar-se com um atalho. Texto no ecrã: *"Código limpo num clique."*
*   **Locução:** "A segunda é [Nome da Extensão de Formatação/Linting]. Adeus a perder tempo com indentação desalinhada ou erros de sintaxe bobos antes do commit."

**Cena 4: Extensão 3 - Colaboração/Temas (0:30 - 0:40)**
*   **Visual:** O autor volta a aparecer em câmara, gesticulando de forma natural, com um sorriso confiante.
*   **Locução:** "E a terceira é [Nome da Terceira Extensão, ex: GitLens ou Tema personalizado], essencial para rastrear cada alteração no repositório sem sair do editor."

**Cena 5: Chamada para Ação (0:40 - 0:48)**
*   **Visual:** Texto centralizado em destaque com as cores do perfil: *"Qual é a tua extensão favorita?"*
*   **Locução:** "Qual é a extensão que não pode faltar no teu editor? Diz-me nos comentários e segue a página para mais dicas de engenharia!"

## Vídeo 2: Bastidores de Projeto: Como Concebi o RegistAgro (De Ideia a Software)

*   **Duração estimada:** 55 a 60 segundos.
*   **Estes:** Storytelling técnico, alternando entre esboços num caderno/esquema de arquitetura e o código a correr no ecrã.
*   **Áudio de fundo:** Música instrumental inspiradora e progressiva.

### Estrutura Cena a Cena

**Cena 1: O Gancho (0:00 - 0:06)**
*   **Visual:** O autor a olhar para o ecrã com uma interface limpa de um projeto. Texto no ecrã: *"Como transformar uma ideia num sistema real."*
*   **Locução:** "Muitas pessoas perguntam como saímos da teoria escolar para construir soluções de software aplicadas. Hoje mostro-vos os bastidores do RegistAgro."

**Cena 2: A Modelação e o Contexto (0:06 - 0:20)**
*   **Visual:** Imagens rápidas do autor a escrever num caderno diagramas de tabelas ou a mostrar esquemas de bases de dados (PostgreSQL/SQL).
*   **Locução:** "Tudo começa na base. Antes de escrever qualquer linha de código, precisei de estruturar a arquitetura de dados e definir os requisitos essenciais para garantir que o sistema respondesse a problemas reais."

**Cena 3: O Desenvolvimento Backend (0:20 - 0:38)**
*   **Visual:** Gravação de ecrã em timelapse do editor de código a compilar rotinas em backend (Node.js/Express ou PHP/PDO), mostrando a clareza da lógica implementada.
*   **Locução:** "No backend, o foco foi criar APIs robustas, validar regras de negócio com rigor e manter a estabilidade. Afinal, um bom software não vive só do que se vê no ecrã, mas principalmente da robustez por trás."

**Cena 4: A Conclusão e o Portfólio (0:38 - 0:50)**
*   **Visual:** O autor volta ao plano principal, apontando subtilmente para o portátil onde o portfólio web está aberto.
*   **Locução:** "Este tipo de projeto — assim como a Cantina Online e outras aplicações que desenvolvi — ajudou-me a consolidar a minha base como Desenvolvedor Júnior e a preparar-me para desafios profissionais."

**Cena 5: Chamada para Ação (0:50 - 0:58)**
*   **Visual:** Texto final com o link visível: *"Vê o portfólio completo no link da bio!"*
*   **Locução:** "Queres ver mais detalhes sobre os meus projetos e código? O link está na bio. Vemo-nos no próximo vídeo!"
